# Database Schema

This document outlines the database schema for the Curtin Honestly API. The application uses PostgreSQL and manages the schema via Hibernate (Spring Data JPA).

## Tables

### `units`
Stores information about university units.

| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | PK, Not Null, Unique | Unique identifier for the unit. |
| `code` | VARCHAR(255) | Unique, Not Null | The unit code (e.g., "COMP1000"). |
| `name` | VARCHAR(255) | Not Null | The full name of the unit. |
| `description` | TEXT | Not Null | Detailed description of the unit. |
| `unit_link` | VARCHAR(500) | Nullable | Link to the unit handbook page. |
| `faculty` | VARCHAR(255) | Not Null | Enum: `Faculty` values. |
| `level` | VARCHAR(50) | Not Null | Enum: `UnitLevel` (UNDERGRADUATE / POSTGRADUATE). |
| `area` | VARCHAR(255) | Nullable | Study area (e.g., "WASM..."). |
| `field_of_education` | VARCHAR(100) | Nullable | Education field code/name. |
| `credits` | INTEGER | Nullable | Credit points. |
| `contact_hours` | INTEGER | Nullable | Weekly contact hours. |
| `result_type` | VARCHAR(50) | Nullable | Grading type (e.g., "Grade/Mark"). |

**Relationships:**
- One-to-Many to `reviews` (mapped by `unit_id`).
- One-to-Many to `unit_tuition_patterns` (mapped by `unit_code`).
- One-to-Many to `unit_prerequisite_groups` (mapped by `unit_code`).

### `users`
Stores user account information.

| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | PK, Not Null | Unique identifier for the user. |
| `email` | VARCHAR(255) | Unique, Not Null | User's email address. |
| `password` | VARCHAR(255) | Not Null | Hashed password (JSON Ignored). |
| `username` | VARCHAR(255) | Nullable | Display name for the user. |

**Relationships:**
- One-to-Many to `reviews` (mapped by `user_id`).
- ElementCollection `roles` (stored in `user_roles` table).

### `user_roles`
Join table for user roles (generated by `@ElementCollection` in `User`).

| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `user_id` | UUID | FK -> `users.id` | The user the role belongs to. |
| `roles` | VARCHAR(255) | Not Null | Enum: `UserRole` (e.g., "ROLE_USER"). |

### `reviews`
Stores student reviews for units.

| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | PK, Not Null | Unique identifier for the review. |
| `rating` | INTEGER | Not Null | Overall rating (0-10). |
| `final_grade` | INTEGER | Nullable | Final grade received. |
| `review_text` | VARCHAR(255) | Nullable | Text content of the review. |
| `semester_taken` | VARCHAR(255) | Nullable | When the unit was taken. |
| `professor` | VARCHAR(255) | Nullable | Professor's name. |
| `workload` | INTEGER | Not Null | Workload rating (0-10). |
| `has_exam` | BOOLEAN | Not Null | Whether the unit had an exam. |
| `would_take_again` | BOOLEAN | Not Null | Recommendation flag. |
| `unit_id` | UUID | FK -> `units.id` | The unit being reviewed. |
| `user_id` | UUID | FK -> `users.id` | The author of the review. |

### `unit_tuition_patterns`
Stores teaching formats for a unit.

| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | BIGSERIAL | PK, Not Null | Auto-incrementing ID. |
| `unit_code` | VARCHAR(255) | FK -> `units.code` | The unit this pattern belongs to. |
| `type` | VARCHAR(50) | Nullable | Type of class (e.g., "Lecture"). |
| `duration` | VARCHAR(100) | Nullable | Duration (e.g., "1 x 2 hours"). |

### `unit_prerequisite_groups`
Groups prerequisite rules (e.g., "One of the following").

| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | BIGSERIAL | PK, Not Null | Auto-incrementing ID. |
| `unit_code` | VARCHAR(255) | FK -> `units.code` | The unit these prerequisites apply to. |
| `group_name` | VARCHAR(50) | Nullable | Name of the group. |
| `requirement` | VARCHAR(10) | Nullable | Logic: "one" or "all". |
| `position` | INTEGER | Nullable | Ordering position. |

**Relationships:**
- One-to-Many to `unit_prerequisite_options` (mapped by `group_id`).

### `unit_prerequisite_options`
Specific units within a prerequisite group.

| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | BIGSERIAL | PK, Not Null | Auto-incrementing ID. |
| `group_id` | BIGINT | FK -> `unit_prerequisite_groups.id` | The parent group. |
| `code` | VARCHAR(30) | Nullable | Unit code of the prerequisite. |
| `title` | VARCHAR(255) | Nullable | Title of the prerequisite unit. |

## Enums

### Faculty
Stored as String in `units` table.
- `BUSINESS_AND_LAW`
- `HEALTH_SCIENCES`
- `HUMANITIES`
- `SCIENCE_AND_ENGINEERING`
- `ABORIGINAL_STUDIES`

### UserRole
Stored as String in `user_roles` table.
- `ROLE_USER`
- `ROLE_ADMIN`

## Behaviors & Configurations

- **DDL Auto:** `update` (Hibernate automatically updates the schema on startup).
- **JSON Serialization:**
    - `units` -> `reviews` (Unit is ignored in Review to prevent loops).
    - `units` -> `tuitionPatterns` (Unit is ignored).
    - `units` -> `prerequisiteGroups` (Unit is ignored).
    - `unit_prerequisite_groups` -> `options` (Group is ignored).
    - `users` -> `password` (Always ignored).
- **Cascade Operations:**
    - Deleting a `Unit` cascades to `reviews`, `tuitionPatterns`, and `prerequisiteGroups`.
    - Deleting a `User` cascades to `reviews`.
    - Deleting a `UnitPrerequisiteGroup` cascades to `options`.
